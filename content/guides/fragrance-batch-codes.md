title: Fragrance batch codes: what they tell you
description: What the batch code on a perfume box and bottle is, where to find it, and what it can and can't tell you about age and authenticity.

Almost every fragrance carries a short batch code. It's easy to miss, but it's one of the most useful things to check when you buy.

## What a batch code is

A batch code identifies the production run a bottle came from. Manufacturers use it to trace products, for example if there's a quality problem. It's usually a short mix of letters and numbers.

## Where to find it

- **On the box:** often printed or stamped on the bottom or a side flap.
- **On the bottle:** printed or etched on the base, or on a small sticker.

The code on the box and the code on the bottle should match.

## What it can tell you

**Roughly how old the bottle is.** Many codes can be decoded to an approximate production date. Free online batch-code checkers do this for many brands. Formats vary by manufacturer, and the checkers aren't official, so treat the result as a guide, not a guarantee.

**Which formulation you have.** Brands sometimes change a fragrance's formula. Enthusiasts use batch codes to tell older and newer versions apart.

## What it can't tell you

**It isn't an expiry date.** A production date says when the fragrance was made, not when it goes off. Many fragrances also carry an "open jar" symbol with a number, such as 36M, showing how many months it's best used within after opening.

**It doesn't prove a bottle is genuine.** Counterfeiters copy codes too. A code that decodes properly is a good sign, not proof.

## Warning signs

- **No code at all**, on the box or the bottle.
- **A code that's been scratched or cut off.** This is sometimes done to hide which distributor stock came from. It's common on grey-market stock. See [grey-market fragrance risks](grey-market-fragrance-risks.html).
- **Box and bottle codes that don't match.**
- **A code in a different style** from other bottles of the same brand.

## Does age matter?

Fragrance stored unopened, cool and away from light usually keeps well for years. Heat, light and air are what damage it. An older bottle isn't necessarily a worse one, but it's worth knowing what you're buying. For more checks, read [how to avoid fake fragrances](avoid-fake-fragrances-online.html).
